# 2026-07-31 代码评审：liquor-dashboard

## 项目本质
酒水（直营+分销）经营分析驾驶舱。Next.js 16 + React 19 + Tailwind4 + Prisma7，数据库是 **Supabase PostgreSQL**（非 README 所述 SQLite）。带 base64 cookie 登录认证，单用户。

## 关键发现
1. **认证严重漏洞**：auth_token 仅为 `base64(JSON{u,t})`，无签名/密钥，可伪造绕过登录；`.env`/`.env.example` 存明文弱口令；cookie `secure:false`。
2. **现金流模型（已与用户确认正确）**：分销是"中转"模式——下游客户付全款、上游公司收成本，系统只把净额（毛利）记一笔现金流入，且分销没有独立的"付公司成本"现金流出，故净额即真实现金影响，**设计正确，不是 bug**。首页 page.tsx 第173-174行注释写的"分销发货金额 - 分销成本"公式与实现（净毛利）不符，属注释误导，可顺手修正。
   直营仅记录"已收"部分的现金流入，无后续"补收应收"机制（minor，非失真）。
3. **README 与实现严重不符**：写"SQLite/单机/本机存储"，实为 Supabase 云 PG；"后续计划：迁移 Supabase" 实际已用 Supabase。
4. **分销客户删除会失败**：Distributor 无 onDelete Cascade，DELETE 在有子记录时报错，与前端"相关数据一并删除"提示矛盾。
5. **API 无输入校验**；金额 `Math.round` 截断后存储导出；dashboard 全表 findMany+reduce，大数据量性能风险。
